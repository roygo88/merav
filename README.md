# Digitop homepage redesign (concept)

A redesign concept for the homepage of digitop.co.il: Hebrew RTL, a single static HTML file with no build step.

- `index.html`: the redesign (contour-map hero, staircase process, one contact form)
- `v1.html`: the earlier, simpler draft

Lighthouse (lab, local): mobile 97 / desktop 99 performance; 100 accessibility, best practices and SEO. Total about 91 KB in 6 requests.

The page is marked `noindex` because it is a design concept, not the live site. The contact form is a demo and sends nothing.
